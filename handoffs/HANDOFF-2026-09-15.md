## 1. O que é

`AMD-NR-ReShade-Installer` é o gerenciador gráfico do add-on
[dlss5-neural-amd](https://github.com/zmodelerlover/dlss5-neural-amd), que roda a rede de Neural
Rendering do DLSS 5 em placas Radeon através do ReShade.

Ele resolve as duas coisas que o installer de terminal não resolvia:

- os arquivos vinham do canal `files` do Discord, e achar aquilo era onde a maioria travava;
- era um terminal: não mostrava biblioteca, não detectava GPU, não avisava de versão nova.

Hoje ele **instala tudo sozinho, sem nenhuma janela de terceiros**: add-on, runtime, pesos, o par
do bridge 32-bit e **o próprio ReShade**.

- Repositório: `D:\AMD-NR-ReShade-Installer` (git, branch `master`, ainda **não publicado**).
- Executável publicado: `D:\AMD-NR-ReShade-Installer\dist\AMD-NR-ReShade-Installer.exe`
  (~48 MB, self-contained, não precisa de .NET instalado).
- Dados do usuário: `%AppData%\AmdNrInstaller\` (`cache\`, `logs\`, `games.json`, `settings.json`).

## 2. Decisões já tomadas (não reabrir sem motivo novo)

| Decisão | Por quê |
|---|---|
| **Tudo em C#**, porte do motor Rust | Escolha do usuário. O Rust (`installer/` do outro repo) continua existindo e não foi tocado. |
| .NET 10 + Avalonia 11.3.12, sem framework de MVVM | Mesma pilha do Optiscaler-Client, que é a referência de UX. |
| **Update = checar e avisar**, nunca auto-substituir | O Optiscaler-Client removeu o auto-update em 18/08/2026: com `PublishSingleFile` o Windows trava o exe e o app voltava rodando a build velha. |
| Payloads por **release assets do GitHub**, manifesto por `raw.githubusercontent.com` | Grátis, CDN, aceita `Range` (resume), e **não gasta chamada da API REST** — só o update check gasta. |
| **Base de APIs distribuída** (`payload/api-db.json`), não consulta ao vivo | Medido: depois de ~40 consultas o Cloudflare do PCGamingWiki passou a responder **403 para o .NET** enquanto o curl do mesmo IP passava. Consulta ao vivo do PC de cada usuário não funcionaria em escala. |
| **ReShade extraído do instalador oficial**, não executado | O `.exe` do ReShade é um zip anexado. Extrair dá install silencioso, com backup e desinstalação pelo mesmo motor transacional. Rodar o setup escondido não dá nada disso. |
| Código do Optiscaler-Client **não é reaproveitado** | Ele é GPL-3.0, este repo é MIT. Só o *método* foi copiado (quais chaves de registro varrer, `Binaries\Win64`, fingerprints de DLL). |

## 3. Arquitetura

```
src/AmdNr.Core/     net10.0-windows, sem dependências externas
  Engine.cs         hashes, PE, INI, ownership, paths, MoveFileEx write-through
  Manifest.cs       o manifesto de install (formato byte-a-byte compatível com o C++/Rust)
  Transaction.cs    guard + apply + uninstall (journal, backup, rollback)
  X86Installer.cs   rota 32-bit (bridge)
  Work.cs           presets, Report, preflight, install, uninstall, detect
  Graphics.cs       qual API o jogo usa: imports do exe, engine, fingerprints
  Pcgw.cs           parser do template {{API}} do PCGamingWiki + normalização de título
  ApiDatabase.cs    api-db.json: leitura, lookup por appid e por título
  Scanning.cs       Steam/Epic/GOG/EA/Ubisoft/Battle.net/Xbox
  PayloadManifest / PayloadCache / CoverCache   download, extração, verificação, staging

src/AmdNr.App/      net10.0-windows, Avalonia, single-file self-contained win-x64
tests/AmdNr.Core.Tests/   117 testes
tools/ApiDbBuilder/       gera payload/api-db.json a partir do PCGamingWiki
tools/seed-cache.ps1      enche o cache a partir de arquivos locais (offline / teste)
payload/payload.json      o que baixar, de onde, e qual hash
payload/api-db.json       840 jogos: quais APIs cada um suporta
```

O motor foi portado de `installer/src/engine.rs` e `installer/src/work.rs` do outro repositório.
**Comportamento é contrato**: as frases de recusa são asseridas por teste e o manifesto de install
tem que continuar byte-a-byte igual ao que o instalador C++ escrevia, senão toda instalação já
existente vira "Modified or unsupported install manifest".

## 7. Armadilhas já pagas (não repetir)

- **Cloudflare bloqueia o HttpClient do .NET por impressão TLS.** Cabeçalhos e versão de HTTP não
  mudam nada; o curl do Windows passa. Por isso o `ApiDbBuilder` chama `curl.exe` por processo, e
  por isso a base é distribuída em vez de consultada.
- **`ZipArchive` não abre zip anexado a exe**: os offsets contam do início do zip. Achar o EOCD e
  rebasear (`PayloadCache.OpenAppendedZip`).
- **Regex de campo de template**: `\s*` engole a quebra de linha, então campo vazio rouba a linha
  seguinte como valor. Foi assim que Metro 2033 "suportava" Vulkan e OpenGL. Use `[ \t]*`.
- **O nome do arquivo não diz o que o DLL é.** O `dxgi.dll` do God of War aqui é OptiScaler. Ler
  o recurso de versão antes de dizer "ReShade encontrado".
- **Jogo Unreal**: o add-on vai em `<Projeto>\Binaries\Win64`, não na raiz — a raiz só tem o stub.
- **Jogo com nome em algarismo romano**: "Grand Theft Auto V" → `GTA5.exe`. A escolha do exe
  normaliza romano para dígito, e exclui `*LanguageSelect*`, `*trial*`, crash handlers etc.
- **`$Home` é variável reservada do PowerShell**; e parâmetro `[string]$X` converte objeto em
  string silenciosamente (foi assim que o `seed-cache.ps1` "não achou componente nenhum").
- **Heredoc de Python com `\a`, `\n`, `\\`** estraga caminho e string de C#. Preferir edição direta.
- **A rota 32-bit não instala o `addon64`** e lê os payloads tanto de `files\` quanto da raiz do
  staging.

## 8. Coisas que não cabem nas seções acima e custam tempo se esquecidas

**Esta máquina tem instalações que não vêm daqui.** Pelo handoff do outro projeto, o GTA V
Enhanced e o `D:\pcsx2-v2.8.2-test` rodam o port da **v0.2.18**, que não existe em commit nenhum.
Instalar por este app volta os dois para a v0.2.17 + add-on v0.5.0. Não se perde nada — o que for
deslocado vai para `.dlss5-x86bridge-backups\` e o Desinstalar devolve — mas o experimento da
v0.2.18 sai da pasta. O God of War tem **OptiScaler** como `dxgi.dll`, e por isso o ReShade entra
lá como `d3d11.dll`.

**O `x86-extras` provavelmente é redundante.** O `dxgi.dll` que ele carrega é byte-a-byte o
`ReShade32.dll` do instalador oficial, que o componente `reshade` já baixa. Dá para apontar a rota
32-bit para o `ReShade32.dll` extraído e deixar em `x86-extras` só o `d3d8to9.dll` — menos coisa
para espelhar quando os repositórios forem publicados.

**Formatos que o app escreve** (em `%AppData%\AmdNrInstaller\`):
`games.json` é a lista (caminho, nome, plataforma, appid, rota, `PresetChosen`). `PresetChosen`
vira `true` quando a pessoa escolhe a rota à mão, e daí em diante a detecção não sobrescreve mais.
`settings.json` guarda só o idioma. O cache é `cache\<componente>\<versão>\`, e `cache\staging\`
tem as pastas montadas por **hard link** — instalar não copia os 141 MB de novo.

**Capas** vêm de `https://cdn.cloudflare.steamstatic.com/steam/apps/<appid>/library_600x900.jpg`,
sem API key, com `header.jpg` como alternativa. Jogo sem appid fica com o bloco colorido.

**`config.json`** (ao lado do exe, e opcionalmente em `%AppData%`) só sobrescreve os padrões, que
já apontam para `zmodelerlover/AMD-NR-ReShade-Installer` e `zmodelerlover/AMD-NR-Extras`. Uma
cópia do exe sozinha continua sabendo onde procurar.

**Uninstall preserva configuração de propósito.** `dlss5-neural.ini` e `ReShade.ini` ficam, e por
isso o `dlss5-neural.install.json` também fica, com as entradas preservadas. Isso é herdado do
motor Rust e é testado.

**Não existe CI ainda.** Nem workflow de release. Quando publicar: build `win-x64` single-file,
zip, e os SHA-256 no corpo da release.

**O fonte Rust de referência** não está neste repositório. Para reler o original de qualquer
comportamento:

```powershell
git -C D:\dlss5 show origin/master:installer/src/engine.rs   # e work.rs
```

**O harness de render headless é descartável** e vive no scratchpad da sessão
(`%TEMP%\claude\...\scratchpad\ui-headless\`), fora do repositório: projeto de console referenciando
`src/AmdNr.App`, com `Avalonia.Headless` + `Avalonia.Skia` 11.3.12 e `CaptureRenderedFrame()`.
Some quando a sessão acaba; refazer é meia dúzia de linhas. Ele existe porque o usuário joga nesta
máquina e abrir janela no meio do jogo não é opção.

**O post do Discord do outro projeto está desatualizado por causa daqui.**
`C:\Users\claudinhh\Desktop\discord-v0.5.0\POST-2-install.md` manda baixar dois arquivos do canal
`files`; com este app isso vira "abra o app". Rever antes de postar.
